# Hochgeladene Dateien

Alles, was im Verwaltungsbereich hochgeladen wird, landet hier:

    logos/       Sponsorenlogos
    dokumente/   Satzung, Ordnungen, Aufnahmeantrag, Sprachrohr (PDF)
    bilder/      Fotos für Startseite und Sprachrohr

Die Dateien gehören zum Inhalt der Website und werden mit eingecheckt — nur so
funktionieren sie auch, wenn die Seite zusätzlich statisch über GitHub Pages
ausgeliefert wird.
